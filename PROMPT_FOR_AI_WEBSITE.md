1. ИНФОРМАЦИЯ О ПРОЕКТЕ И ТЕХНИЧЕСКИЙ СТЕК
==========================================================================

Название приложения: Videx
Автор / Разработчик: XZ-LITE
Платформа: Android 8.0+ (Target API 35 / Android 15 Ready)
Репозиторий на GitHub: https://github.com/XZ-LITE/Videx
Канал в Telegram: https://t.me/videx_app

Технологический стек приложения:
- Язык и UI: Kotlin, Jetpack Compose, Material Design 3 (Material You Dynamic Colors).
- Движок экстракции: Встроенный нативный Python 3.13 рантайм (Chaquopy) + ядро yt-dlp (обновляемое по воздуху OTA).
- Обработка медиа: Нативный бинарник FFmpeg 6.1.1 (64KB page-aligned под Android 15).
- Фоновые службы: Android WorkManager DataSync Foreground Service, WakeLock & WifiLock (30 мин защита батареи).
- База данных: SQLite Room v5 с индексами и автоматическими миграциями.
- Хранилище: Scoped Storage, Storage Access Framework (SAF) для SD-карт, MediaStore API.
- Плееры и Графика: ExoPlayer (Media3), Picture-in-Picture (PiP), Coil Image Loader, Haptic Feedback.
