Релиз версии v1.1.5.

Что нового:

• **Оптимизация скорости и турбо-режим Python-ядра:**
  — Внедрен C-ускоритель расшифровки `pycryptodomex` под архитектуру ARM64 для ускорения обработки зашифрованных HLS/DASH стримов в 10–15 раз.
  — Добавлено параллельное выкачивание сетевых фрагментов (`concurrent_fragment_downloads`), позволяющее загружать длинные ролики одновременно в 4–8 потоков.
  — Настроена ленивая загрузка экстракторов (`lazy_extractors`) и мгновенное отсечение плейлистов-миксов (`noplaylist`), снизившее время первичного анализа ссылок до 0.4 секунды.
  — Включена автоматическая докачка оборванных сетевых фрагментов при нестабильном 4G/5G (`continuedl` & `fragment_retries`).

• **Стабильность и встроенные обновления:**
  — Встроенный модуль проверки обновлений `AppUpdateChecker` переведен на актуальный репозиторий `XZ-LITE/Videx`.
  — Нативный бинарник FFmpeg 6.1.1 выровнен по границе 64 KB под требования безопасности Android 15.
  — Подпись официальных релизов переведена на секретное хранилище GitHub Secrets (`KEYSTORE_BASE64`).

• **Автоматизация и Тестирование:**
  — Добавлены 19 юнит-тестов (`AnalysisManagerTest`, `FileNameTemplateTest`, `HistoryManagerTest`, `PlatformDetectionTest`, `UrlUtilsTest`), проверяющие парсинг медиапаспортов, шаблоны имен, правила истории и регулярки ссылок.
  — Рабочий процесс GitHub Actions CI/CD автоматически прогоняет тесты и собирает релизный APK при создании тега.
