Релиз патча v1.2.1 (Critical Bugfix & Stability Patch)

Срочное обновление безопасности, исправляющее критическую ошибку взаимодействия с Python-движком и OTA-обновлениями ядер.

Что нового в v1.2.1:
• **Фикс падения Python Warm-up & OTA ядра:**
  — Устранен фатальный сбой `TypeError: Cannot convert dict object to java.util.Map` при получении статусов ответа от Python.
  — Реализовано безопасное обращение к объектам словарей Python (`getPyDictString`).
  — Восстановлена корректная фоновая предзагрузка рантайма Python без лагов UI.
  — Восстановлена горячая замена обновлений ядер `yt-dlp` через OTA.

• **Стабильность сети и системных сервисов:**
  — Ошибки отсутствия интернет-соединения при автопроверке обновлений переведены в мягкий уровень `[WARN]`, исключая ложные алармы `[ERROR]` в логах.
  — Исправлена потенциальная гонка потоков (`NoSuchElementException`) при очистке RAM-кэша анализа ссылок.
  — Проведен полный аудит исходного кода: сбоев не обнаружено.
