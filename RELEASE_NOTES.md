Релиз версии v1.2.0. (Major Security & Background Media Update)

Масштабное обновление безопасности, стабильности работы Python-ядра и фонового воспроизведения.

Что нового (v1.2.0):
• **Фоновый аудиоплеер (Media3 Service):**
  — Внедрен полноценный системный сервис `PlaybackService` (`MediaSessionService`). Теперь при сворачивании приложения или закрытии экрана плеера музыка продолжает играть в фоне без обрывов.

• **Безопасность и подпись (Audit Fixes):**
  — Удалены хардкоды ключей подписи. Добавлена безопасная загрузка через `local.properties`.
  — **Защита OTA:** Внедрена проверка хэша SHA-256 для загружаемых архивов ядра `yt-dlp`.
  — **Защита от подмены APK:** Добавлена автоматическая проверка отпечатков подписи (Signature Digest) скачиваемых обновлений перед их установкой.

• **Стабильность Python-движка и файлов:**
  — Исправлен критический баг с отступами в `ytdlp_wrapper.py`, вызывавший падение при отсутствии пути к кэшу.
  — Синхронизированы форматы паспорта метаданных между Python и Kotlin.
  — Включена полноценная валидация SSL-сертификатов при сетевых запросах `yt-dlp`.
  — **Удаление зомби-файлов:** При ошибках сохранения в `MediaStore` файл с флагом `IS_PENDING` корректно удаляется из памяти устройства, не засоряя галерею.
  — В `AuthManager` заменено тотальное удаление `WebStorage` на точечную очистку по доменам при выходе из аккаунта.
