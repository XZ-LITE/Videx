Функционал

Инженерный подход

Функционал, созданный для полного контроля над загрузками.

Ядро и FFmpeg

Python 3.13 (Chaquopy) для алгоритмов yt-dlp. Нативная сборка FFmpeg 6.1.1 для склейки 4K потоков. OTA обновления ядра.

Фоновая очередь

Многопоточность до 3 слотов (WorkManager). Защита батареи WakeLock. Раздельные лимиты скорости для Wi-Fi и 4G.

Смарт-детектор

Авто-перехват ссылок из буфера обмена. Обход блокировок (Impersonate) и пропуск спонсорской рекламы (SponsorBlock).

Встроенный медиацентр

Видеоплеер ExoPlayer с управлением жестами и режимом Картинка-в-Картинке (PiP). Музыкальный плеер с эквалайзером.

Хранилище и SD-карты

Поддержка Scoped Storage. Системная защита данных при удалении приложения (hasFragileUserData).

БД Room и Дубликаты

Встроенная SQLite база данных с индексами. Автоматически сканирует память смартфона для «исцеления» потерянной истории.

Шаблоны имен

Гибкая настройка названий файлов: Дата_Платформа_Название, Название_Оригинал и автоматическое срезание ID.

Интерактивные пуши

Детальный прогресс в шторке со скоростью и ETA. Кнопки «Поделиться» и «Удалить» прямо в уведомлении.

Dynamic Colors

Интерфейс приложения автоматически подстраивается под цвета ваших обоев на Android 12+ (Material You).

Under the Hood

Умные алгоритмы

Инженерные решения, которых не найти в обычных загрузчиках.

01

Smart Transit

При отправке ссылки через «Поделиться» алгоритм оценивает параметры медиа и тип сети (Wi-Fi / Mobile). Если включён автопилот — загрузка стартует мгновенно без открытия главного окна.

02

Thermal Management

Интеграция с PowerManager.OnThermalStatusChangedListener следит за температурой CPU. При перегреве корутины вносят микро-задержки — сохраняется плавность UI 60/120 FPS.

03

Self-Healing File Tracker

Записи в Room DB привязаны к цифровому отпечатку файла (размер + длительность). Если файл переименован или перенесён — привязка восстанавливается автоматически.

04

Zero-Brick OTA

Обновление Python-ядра через атомарную замену с локальным бэкапом ytdlp_backup.zip. При обрыве сети система мгновенно откатывается к рабочему ядру.

05

SponsorBlock & Impersonate

Встроенная маскировка заголовков браузера для обхода возрастных ограничений и автоматический пропуск интегрированной спонсорской рекламы в роликах.

06

FFmpeg 16KB Aligned

Нативная сборка FFmpeg под новые требования безопасности Android 15 (16KB Page Alignment). Высокоскоростная склейка 4K видео и аудио потоков.

07

Exynos & Snapdragon Recovery

Во избежание зависания видеокадров при быстрой перемотке плеер приостанавливает декодирование на время движения ползунка — исключаются аппаратные сбои видеодрайвера.
