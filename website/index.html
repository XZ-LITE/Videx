Универсальный транзит

Автопилот для мессенджеров

Поделитесь ссылкой из TikTok или Instagram с Videx. Приложение в фоне скачает файл, сожмет его и само вызовет системное окно отправки. Вам остается лишь выбрать контакт.

  • Оптимизация видео: Конвертация в H.264 (1080p, 720p) для инлайн-воспроизведения прямо в чатах Telegram и WhatsApp.
  • Сжатие фото: JPEG-оптимизация каруселей на 70% без потери качества.
  • Тихий режим (Silent Share): Фоновое скачивание без открытия главного интерфейса.

Инженерный подход

Функционал, созданный для полного контроля над загрузками.

Ядро и FFmpeg

Python 3.13 (Chaquopy) для алгоритмов yt-dlp. Нативная сборка FFmpeg 6.1.1 для склейки 4K потоков. OTA обновления ядра.

Фоновая очередь

Многопоточность до 3 слотов (WorkManager). Защита батареи WakeLock. Раздельные лимиты скорости для Wi-Fi и 4G.

Смарт-детектор

Авто-перехват ссылок из буфера обмена. Обход блокировок (Impersonate) и пропуск спонсорской рекламы (SponsorBlock).

Встроенный медиацентр

Видеоплеер ExoPlayer с управлением жестами и режимом Картинка-в-Картинке (PiP). Музыкальный плеер с эквалайзером.

Хранилище и SD-карты

Поддержка Scoped Storage. Системная защита данных при удалении приложения (hasFragileUserData).

Room и Анти-дубликаты

SQLite база с индексами. Предупреждает о повторных скачиваниях. Сканирует память смартфона для «исцеления» потерянной истории.
