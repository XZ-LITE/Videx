**Videx** — open-source приложение для Android, предназначенное для скачивания видео, аудио и фото-каруселей с более чем 1000+ веб-сервисов. Работает автономно: обработка и анализ ссылок происходят непосредственно на устройстве с помощью CPython 3.13 и `yt-dlp`.

## Ключевые возможности

<table>
<tr>
<td width="50%" valign="top">

### Загрузка медиаконтента
- **Максимальное качество**: Выбор видеопотоков до 4K/60FPS с сохранением оригинального битрейта.
- **Извлечение аудио**: Конвертация видеороликов в чистый MP3 или M4A звук.
- **Скачивание фото**: Автоматическое извлечение альбомов, каруселей и слайдшоу из TikTok и Instagram.
- **Пакетные и фоновые загрузки**: Скачивание через `WorkManager` с уведомлениями о прогрессе и ограничением параллельных потоков.

</td>
<td width="50%" valign="top">

### Встроенный видео- и аудиоплеер
- **Видеоплеер (Media3 ExoPlayer)**: Поддержка жестов яркости и громкости, перемотки 10 секунд двойным тапом, выбор соотношения сторон (Fit/Fill/Zoom) и режим «Картинка-в-картинке» (PiP).
- **Аудиоплеер**: Фоновое воспроизведение с обложками и управлением через уведомление `MediaSession`.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Автопилот и транзитный режим
- **Универсальная отправка**: Поделитесь ссылкой с Videx — приложение скачает медиафайл в фоне и мгновенно откроет системное окно (Share Sheet) для отправки в **любой мессенджер** (Telegram, WhatsApp, VK, Viber, Discord и т.д.).
- **Оптимизация файлов**: Автоматическая конвертация видео в компактный формат H.264/HEVC (1080p, 720p) для прямого проигрывания в чатах, а также моментальное JPEG-сжатие фотографий на 70%.
- **Смарт-Детектор**: Автоматический перехват скопированных ссылок из буфера обмена с загрузкой превью-карточки без лишних кликов.

</td>
<td width="50%" valign="top">

### Приватность и Безопасность
- **Локальный CPython**: Весь анализ и скачивание происходят на смартфоне, данные не отправляются на сторонние сервера.
- **Встроенный WebView**: Безопасная авторизация на сайтах через официальные веб-страницы для доступа к приватным подпискам.

</td>
</tr>
</table>

<summary><b>Настройка тактильного отклика и автообновления (нажмите для раскрытия)</b></summary>

- **Настройка тактильного отклика**: Выбор силы отклика (Мягкая, Стандартная, Сильная) и раздельное управление вибрацией для UI-кнопок, жестов видеоплеера и длинных зажатий.
- **Автообновления (OTA)**: Проверка новых релизов приложения на GitHub с возможностью скачивания и установки APK в один клик, а также загрузка свежих алгоритмов `yt-dlp` по воздуху.

</details>

---

<details>
<summary><b>Техническая оптимизация (нажмите для раскрытия)</b></summary>

- **Алгоритм транзитного режима (Smart Transit)**: При отправке ссылки в Videx через системную кнопку «Поделиться» алгоритм оценивает параметры медиафайла и текущий тип сети (Wi-Fi или Mobile). Если включен автопилот, загрузка стартует мгновенно без открывания главного окна приложения.
- **Управление нагрузкой CPU (Thermal Management)**: Интеграция с `PowerManager.OnThermalStatusChangedListener` позволяет отслеживать температуру процессора во время скачивания. При перегреве смартфона корутины вносят микро-задержки для охлаждения CPU и сохранения высокой плавности UI.
- **Синхронизация истории с диском**: Записи в Room DB привязаны не только к прямому пути файла, но и к его цифровому отпечатку (Размер + Длительность медиа). Если файл переименован или перенесен пользователем через сторонний файловый менеджер, Videx автоматически восстанавливает привязку при следующем запуске.
- **Обновление ядра Python (OTA)**: Механизм обновления Python-ядра использует атомарную замену файлов архива с созданием локального бэкапа (`ytdlp_backup.zip`). В случае обрыва сети или ошибки распаковки система мгновенно откатывается к рабочему ядру.
- **Обход блокировок (SponsorBlock & Impersonate)**: Встроенная маскировка заголовков браузера для обхода возрастных ограничений и автоматический пропуск интегрированной спонсорской рекламы в роликах.
- **Нативная сборка FFmpeg (Android 15 16KB Page Aligned)**: Высокоскоростная склейка видео и аудио потоков 4K через нативный бинарник FFmpeg, оптимизированный под новые требования безопасности операционной системы Android 15.
- **Оптимизация декодера видео**: Во избежание зависания видеокадров при быстрой перемотке плеер приостанавливает декодирование кадров на время движения ползунка, исключая аппаратные сбои видеодрайвера.

</details>

## Архитектура и технологический стек

| Компонент | Используемые технологии |
| :--- | :--- |
| **Язык программирования** | Kotlin (JDK 17) |
| **Пользовательский интерфейс** | Jetpack Compose, Material 3 Expressive, Dynamic Colors |
| **Архитектура** | MVVM, ViewModels, StateFlow, Coroutines |
| **Медиаплеер** | AndroidX Media3 ExoPlayer, MediaSession |
| **База данных** | Room Database (SQLite v5 с автомиграциями) |
| **Фоновые задачи** | AndroidX WorkManager (Expedited DataSync Workers) |
| **Python-движок** | Chaquopy (CPython 3.13, `yt-dlp`, `requests`) |
| **Сеть и кэш** | OkHttp 4, Coil (Video & Image Disk Cache) |

<details>
<summary><b>Инструкция по сборке из исходников (нажмите для раскрытия)</b></summary>

### Требования
- Android Studio Ladybug (2024.2.1) или новее
- JDK 17
- Android SDK 36 (minSdk 26, targetSdk 36)

### Сборка Release APK
Для сборки готового к установке APK-файла выполните команду в консоли:

```bash
./gradlew assembleRelease
```

Готовый файл будет находиться по пути:
`app/build/outputs/apk/release/app-release.apk`

</details>
